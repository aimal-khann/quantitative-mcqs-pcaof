# PCAO-F Quantitative Reasoning Portal

Static HTML/CSS/JS quiz & cheat-sheet web application for the 60-question no-calculator PCAO-F Quantitative Reasoning bank.

- `index.html` — Overview, live progress ring, quick mental-math check, and 5 category cards
- `tips.html` — Quick Revision Cheat Sheet, interactive walkthrough simulator, 5-step solving method, category tips & traps, and warm-up drills
- `quiz.html` — Full 60-MCQ split-pane workbench with 1–60 jump matrix, category/status filters, confirm-to-reveal breakdowns, local progress saving (`localStorage`), and PDF export
- `styles.css` — Executive Sapphire Light & Maritime Navy Dark themes (`☀️` / `🌙`)
- `app.js` & `questions.js` — Application logic and all 60 scenario MCQs
